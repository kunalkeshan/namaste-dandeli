## 2. Measure the eight routes

For each: measure the real road route, then in `src/content/routes.ts` replace
`unconfirmed(...)` with:

```ts
distance: confirmed({ km: 68, drive: '1 hr 45 min' }, '2026-11-05', 'Google Maps');
```

They will start rendering immediately. **Do not estimate** — see
`docs/dandeli-facts.md` for what happened last time.

## 3. Deploy

```bash
pnpm verify          # must be green
vercel link
vercel --prod
```

`vercel.json` sets the build, security headers and immutable caching for
`/photos` and `/_astro`.

**No `SITE_URL` needed.** `astro.config.mjs` reads
`VERCEL_PROJECT_PRODUCTION_URL`, which Vercel sets to the shortest production custom
domain automatically — so attaching the domain in Vercel is enough, and canonical
URLs, og:image and the sitemap all follow on the next deploy. Previews get their own
URL the same way; use those to show Irshad real pages.

Only set `SITE_URL` to override that, e.g. to pin a specific domain when several are
attached.

## 4. Immediately after deploy — the highest-value step

1. **Replace the 404 URL on his Google Business Profile.** This is the single most
   valuable action in the whole project.
2. Add the five secondary categories (`docs/seo.md`).
3. Submit the sitemap in Search Console.
4. Check the OG card renders by pasting the URL into WhatsApp.

## 5. Ongoing

| When                            | Do                                                                          |
| ------------------------------- | --------------------------------------------------------------------------- |
| Review count moves meaningfully | `pnpm og` — the card is a static image                                      |
| Before any content refresh      | Re-pull reviews; authors can edit or delete                                 |
| A fact gets confirmed           | Replace `unconfirmed(...)` with `confirmed(...)` and re-run `pnpm blockers` |
| Monthly                         | Verify hotlinked Commons images still resolve (`pnpm verify:content`)       |

## Known accepted trade-offs

- **Hero images are hotlinked** from Wikimedia Commons — a third-party runtime
  dependency, chosen for low asset weight. All URLs sit in one file for a quick swap.
- **Vehicle photos are model shots**, not his cars. Disclosed on the page.
- **The logo is a redraw.** Faithful, but not the designer's original.
- **No distances render anywhere** until the eight routes are measured.
